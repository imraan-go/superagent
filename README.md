# tj-lhos-panel — Personal Super-Agent Dashboard

A Grok-style, single-user agentic platform (Next.js full-stack) that drives the
self-hosted **LHOS agent computer** (`/root/e2b-agent-vm`) through its REST API + MCP,
with live VNC takeover, agent orchestration, token/cost metering, scheduling,
connectors (Composio / Pipedream), and a **Manage** mode for the E2B system itself.

> **Start here (AI or human):** read `docs/CONTEXT.md`, then `TODO.md`.
> Cursor rules in `.cursor/rules/` are auto-applied and link everything together.

## Layout
```
.cursor/rules/        Cursor AI rules (project, design, api, security, workflow)
docs/CONTEXT.md       Master context & memory — the single source of truth
docs/ARCHITECTURE.md  App architecture, DB schema (Postgres+pgvector), Docker/Caddy
docs/API_REFERENCE.md LHOS REST API (what the Next.js backend calls)
docs/MCP_REFERENCE.md All 100 MCP tools, grouped, with usage order
docs/DESIGN_SYSTEM.md Directive design spec (non-generic, Grok-inspired-but-distinct)
docs/INTEGRATIONS.md  Model vendors, Composio, Pipedream, webhooks, VNC embed
docs/MANAGE_TAB.md    The Agent/Manage switch — E2B system dashboard spec
docs/skills/          Reusable how-to skills for the AI building this
config/               JSON schemas + model registry (loaded at runtime)
scripts/sync-env.sh   Pulls live tokens from the agent server into .env.local
TODO.md               Build order (phased)
FUTURE_SCOPE.md       Later ideas
CHANGELOG.md          Keep updated on every meaningful change
PROMPT.md             The kickoff prompt to paste into Cursor
```

## Golden rules
1. **Secrets never in code or docs.** `.env.local` is generated by `scripts/sync-env.sh` (reads `/root/e2b-agent-vm/secrets/`). Only `.env.example` is committed.
2. **Update `CHANGELOG.md` + `TODO.md` after every work session.** That is how context survives between AI sessions.
3. **Single user (owner-only login).** No multi-tenant complexity, but keep the schema ready for it.
4. Backend talks to LHOS; the browser never holds the LHOS bearer token.
